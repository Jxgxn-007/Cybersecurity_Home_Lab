# Cybersecurity Home Lab

## Overview
A controlled cybersecurity home lab project demonstrating web application security testing, vulnerability assessment, attack scenarios, and security monitoring concepts.

## Technologies
- Ubuntu
- DVWA
- Apache
- PHP
- MariaDB
- Nmap
- Hydra
- Wazuh
- VirtualBox

## Attack Scenarios
- Brute Force
- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection

## Security Monitoring
Wazuh-based monitoring workflow and simulated detection scenarios are documented in the final project report.

## Deliverables
- Final Presentation
- Final Project Report
